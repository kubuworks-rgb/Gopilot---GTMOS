# Execution plans (historical)

These were the working plans for building GoPilot. **None of them is active.**

They lived under `active/` long after the work they described was finished or
abandoned, which made the directory name a lie. Rather than delete them, they
are archived here: a plan that was followed is a reasonable record of why the
code looks the way it does, and a plan that was abandoned is sometimes a more
useful record than one that was not.

Read them as history, not as intent. Where a plan disagrees with the code, the
code is right.

For what the system actually does now:

- [`README.md`](../../../README.md) — what it is and how to run it
- [`ARCHITECTURE.md`](../../../ARCHITECTURE.md) — how it fits together
- [`docs/EXTENDING.md`](../../EXTENDING.md) — where to put your hands
- [`docs/qa/LIVE_E2E_FINDINGS.md`](../../qa/LIVE_E2E_FINDINGS.md) — what was
  verified against real infrastructure
