# Source Policy

Allowed: public company/product/job pages, public RSS, public GitHub, public YouTube
metadata/transcripts when legitimately accessible, public business information, and
user-authorized sources. Adapters must respect robots, platform terms, rate limits,
copyright, and configured jurisdictional policy.

Prohibited: CAPTCHA/paywall bypass, credential harvesting, private/session-backed
social scraping, unauthorized cookie reuse, private personal data, mass contact
scraping, platform-control evasion, or request-triggered dependency installation.
Unsupported or authentication-required sources return typed failures, never bypasses.
